# EchoCrew Frontend Application 💻

Modular client web application structure organized with component layout templates, custom hooks, API services, type definitions, and CSS styling system.

---

## 📂 Frontend Architecture

```
frontend/
│
├── src/
│   ├── components/    # Reusable UI components (Navbar, StatusBadge, etc.)
│   ├── pages/         # View pages (Dashboard, Login, Reports)
│   ├── layouts/       # Main container and app shell layouts
│   ├── services/      # Backend API communication wrappers
│   ├── hooks/         # Custom React/JS utility hooks
│   ├── context/       # Authentication & application context providers
│   ├── types/         # TypeScript / JSDoc type definitions
│   ├── utils/         # Constants and data formatting functions
│   ├── assets/        # Visual icons, SVG assets, and static media
│   └── styles/        # CSS variables and main design tokens
│
├── public/            # Public static assets & robots.txt
├── tests/             # Component & integration test suites
└── README.md
```

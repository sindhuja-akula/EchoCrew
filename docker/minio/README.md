# MinIO Object Storage Configuration 📦

MinIO provides local S3-compatible object storage for file uploads, media storage, and document attachments during local development.

---

## 🛠️ Configuration Details

- **Console Port**: `9001`
- **API Port**: `9000`
- **Default Access Key**: `minioadmin`
- **Default Secret Key**: `minioadmin`

When the MinIO container service is active in `docker-compose.yml`, access the admin console at `http://localhost:9001`.

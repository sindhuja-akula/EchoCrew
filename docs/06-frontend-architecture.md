# 06 - Frontend Architecture 💻

## Client Interface Design
The EchoCrew frontend is structured as a modular single-page web app.

### Key Directories
- **`src/components/`**: Atomic visual elements (Status badges, navbars, cards).
- **`src/pages/`**: View layouts for Dashboard, Reports, Tasks, and Fleet Management.
- **`src/services/`**: API fetchers interfacing with backend `/api/v1` routes.
- **`src/styles/`**: Centralized design system tokens, variables, and dark mode palette.
